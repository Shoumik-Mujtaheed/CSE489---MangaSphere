1. User Roles
Normal Users (Readers): The main audience of the app. They can browse, read, download, and customize their experience.
Admins (Managers/Curators): Have access to a special dashboard or admin panel to control platform content and manage user activity.
2. Admin Workflow
Admins are responsible for maintaining the manga database and ensuring users have a smooth reading experience.
Admin Account Login: Only admins can log into the restricted admin panel.
Manga Upload & Database Control
Admins can upload new manga/comics directly into the app’s database (title, author, cover, tags/genres, chapters, pages).
They can also edit/update/delete existing manga.
They may approve or reject manga synced from external APIs (so the catalog remains curated).
User Management
View all registered users.
Suspend abusive accounts or assign special permissions if needed.
Track popular manga and user engagement through analytics.
Content Organization
Tag and categorize manga under genres, authors, or character appearances.
Feature mangas on the home page for recommendation.

3. User Workflow (Normal Readers)
Users interact mainly with the manga library, customization features, and reading tools.
Onboarding & Profiles
Users create accounts (email, social login, or guest access).
They can customize their profile with username, avatar, and reading preferences (genres, favorite characters, themes like dark/light mode).
Comic Library & Catalog
Library sources:
Admin-uploaded manga (secured in the app’s main database).
Third-party manga from integrated APIs (ensuring wider availability).
Library displays:
Cover thumbnails and titles
Sorting by popularity, latest, author, or genres
Browsing & Discovery
Search system: by title, character, author, genre.
Filtering system: allows narrowing down by tags (shonen, romance, action, etc.), status (completed/ongoing), and API/admin source.
Personalized homepage:
Recommendations based on reading history, favorited genres, or last-viewed content.
Trending manga or admin-curated picks.
Favorites, Bookmarks & Progress Tracking
Users can add manga to their favorites list for easy access.
Bookmarks: Save progress inside specific chapters (e.g., resume at page 15).
Progress tracking: Automatically remembers last read chapter and page.
Offline Access
Users can download manga chapters for offline reading (with storage management inside app settings).
Option to select preferred quality/size for downloads.
Reading Mode
Manga reader supports:
Horizontal/vertical scroll (or "webtoon-style" reading)
Dark/light themes
Zoom
Split-page or single-page display depending on device orientation
Reading history is synced across devices if online.

4. How Admins & Users Interact
Admins feed the app’s ecosystem by uploading curated manga, moderating external API content, and personalizing featured recommendations.
Users interact with admins indirectly, through the accessible manga database. They benefit from admins’ curation when browsing recommendations or searching.
Two-way interaction can exist if admins send announcements (e.g., “New release uploaded” banners or notifications in the app).
